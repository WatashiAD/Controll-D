Troubleshooting

Phone can't connect or URL won't open

1. Ensure your PC and phone are on the same Wi-Fi network.
2. Firewall: allow port 8765.
3. Some guest networks block device-to-device traffic (AP isolation).

Game doesn't see the controller

Controll-D creates a virtual Xbox 360 controller. In the game's controller settings pick the Xbox 360 Controller (Controll-D). On Linux make sure your user can access /dev/uinput. Windows needs the ViGEmBus driver; macOS does not support virtual gamepads yet.

High latency or laggy input

Ethernet for the PC, 5 GHz Wi-Fi for the phone, and keep line-of-sight to the router.

No vibration on iPhone / iOS Safari

iOS does not expose the Web Vibration API. Haptics work on Android Chrome/Firefox/Chromium.

Keyboard or trackpad doesn't type

On macOS grant Accessibility permission to your terminal (System Settings → Privacy & Security). On Linux your user needs /dev/uinput access.
